# Change log

Oldest first. One line per change: time, model, what changed.

**2026-10-31 09:55 CT, Opus 5.5:** Started this log. Earlier history is in git.
**2026-11-01 19:22 CT, Opus 5.5:** Audit fixes, from a Codex audit checked here. Restore now validates the whole backup first (new `src/validate.js`), keeps the pre-restore data on the device with an Undo Last Restore button, rolls back if a cleanup fails, and reports real counts. "Seated Row Machine" is no longer treated as cardio. A full swipe on a set only reveals Delete. History lists unchecked sets as Skipped.
**2026-11-01 19:22 CT, Opus 5.5:** Added iso-lateral exercises: a checkbox in the exercise form, on by default from the name (Iso-Lateral, Single Arm, Single Leg, Torso Rotation, Bulgarian Split Squat, Glute Kickback, Rear Kick). Sets show as 1A, 1B, 2A, 2B. The B side's goal matches the A side, both sides share a set position, rest runs from the same side's last set, each side is half a set of muscle load, and warm-ups pair up. Goal model version 3.

**2026-11-07 16:03 CT, Opus 5.5:** Workout screen: the per-muscle volume bars now sit in a dropdown under the "lbs total" line, closed by default; tap the total to open or close (state is kept while logging sets).
**2026-11-07 16:48 CT, Opus 5.5:** Suggested exercises: removed the hidden "every muscle's usual is at least 3 sets" floor when comparing against recent same-day workouts (core keeps a floor of 1 set). The floor made rarely trained muscles look 3 sets behind, so Crunch, Torso Rotation and Calf Extension kept showing up. Replay of 430 past add-exercise picks: the muscle he trained next was in the top 3 suggestions 82% of the time (was 63%), core shown 150 times (was 270). Weekly fallback unchanged. "1 set" label fixed. New test in tests/goals.test.mjs. Audit checked by a second Opus 5.5.
**2026-11-09 09:04 CT, Opus 5.5:** Goal reps now come from his own sets (today's previous set of the exercise, else that set last time); the model still picks the weight. End-to-end replay of 1,091 past sets: reps within 1 went 65% to 88%, weight and reps both right 48% to 63%. The goal sheet's old "model vs repeating last time" line (an unfair comparison, scored on the data it was tuned on) is replaced by a replay of the last 20 workouts: how often the goal matched what was lifted vs repeating last time. Goal sheet gets a "Reps" row. Goal model version 4. New tools/goal-replay.mjs; tests updated (44 pass). App v68.
**2026-11-09 09:04 CT, Opus 5.5:** Docs and repo cleanup: README rewritten (14.5 KB to 3.9 KB, stale paths and cache advice removed); CHANGELOG.md and tools/ now in git (tools/model-study/ stays local); smoke/stress scripts use relative paths; CLAUDE.md and private notes updated.
