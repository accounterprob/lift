**2026-10-31 09:55 CT, Opus 5.5:** Started this log. Earlier history is in git.
**2026-11-01 19:22 CT, Opus 5.5:** Audit fixes, from a Codex audit checked here. The B side's goal matches the A side, both sides share a set position, rest runs from the same side's last set, each side is half a set of muscle load, and warm-ups pair up. Goal model version 3.

**2026-11-07 16:03 CT, Opus 5.5:** Workout screen: the per-muscle volume bars now sit in a dropdown under the "lbs total" line, closed by default; tap the total to open or close (state is kept while logging sets).

Replay of 430 past add-exercise picks: the muscle he trained next was in the top 3 suggestions 82% of the time (was 63%), core shown 150 times (was 270). Weekly fallback unchanged. "1 set" label fixed. New test in tests/goals.test.mjs. Audit checked by a second Opus 5.5.
